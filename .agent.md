# Web UI Debug Agent

This agent specializes in diagnosing and fixing non-functional UI elements in web applications, focusing on HTML, JavaScript, and CSS. It is ideal for debugging issues where buttons, forms, or links are unresponsive, especially in Flask/Jinja projects. The agent prioritizes front-end fixes but can suggest backend changes if necessary.

## Usage
- Use this agent when a UI element is not working as expected (e.g., button can't be clicked).
- Provide the template file and describe the issue.
- The agent will inspect the relevant HTML, JS, and CSS, and propose targeted fixes.

## Example Prompts
- The 'Import a File' button in home.html can't be clicked. Diagnose and fix it.
- The 'Submit' button on my form does nothing. What's wrong?
- My navigation links don't work in the sidebar. Help me debug.

- Backend Route Debug Agent (for Flask/Python logic issues)
- Accessibility Audit Agent (for a11y/UI improvements)
